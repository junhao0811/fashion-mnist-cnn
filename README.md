# Fashion-MNIST CNN: Image Classification in PyTorch

Neural networks built up step by step in PyTorch, from a hand-coded network to a custom convolutional neural network.

## What's inside (`image_classification.ipynb`)

| Part | What it does |
|---|---|
| **1. Feed-forward network from scratch** | Implements a neural network manually with PyTorch autograd and a hand-written SGD update, trained on **MNIST** handwritten digits |
| **2. Deep neural networks** | Builds and tunes deep fully-connected networks for clothing recognition on **Fashion-MNIST** |
| **3. Convolutional neural network** | Designs a custom **CNN** with configurable feature-map blocks and **batch normalisation**, trained and evaluated for image classification |

Also covers the theory behind activation functions and forward/backward propagation.

## Tech
PyTorch · torchvision · NumPy · Matplotlib

## Run it
Open the notebook in **Google Colab** (recommended, uses a GPU) or Jupyter. Datasets download automatically.
